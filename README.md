# Portfolio

Static one-page portfolio, hosted on GitHub Pages. No build step.

- **Change text, videos, testimonials, email:** edit `content.js`
- **Add a video:** put the `.mp4` in `media/` (keep each under ~25 MB, 720p is plenty) and set `src: "media/name.mp4"` in `content.js`
- **Preview locally:** `python3 -m http.server 4173` then open http://localhost:4173
